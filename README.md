## Overview

This repository contains a single-page portfolio built to present technical work, project depth, and a recruiter-friendly personal brand. The site combines a modern visual direction with project-focused content across machine learning, simulation, analytics, and full-stack development.

## Highlights

- Custom portfolio with a motion-driven hero section and polished UI
- Curated skills section focused on proof-backed technical strengths
- Featured projects across AI, analytics, and full-stack development
- Interactive project presentation with glassmorphism and subtle motion
- Contact form integration using Formspree
- GitHub Pages deployment with custom domain support

## Local Development

This is a static portfolio site. No build step is required.

Run locally from the project folder:

```powershell
python -m http.server 8001
```

Then open:

```text
http://127.0.0.1:8001
```
